GMGN FOMO Helper

An independent private copy of the GMGN FOMO Helper extension. It is not affiliated with GMGN, FOMO, or the original upstream author.

Download the ZIP from GitHub Releases

Manual installation

  1. Download the versioned ZIP and matching .sha256 file.
  2. Verify the ZIP's SHA-256 checksum, then extract it to a permanent folder.
  3. Open chrome://extensions or edge://extensions.
  4. Enable Developer mode.
  5. Select Load unpacked and choose the extracted folder.

Manual updates

Download and verify the new ZIP, replace the extracted files, then select Reload on the extension card. No companion application is required.

Safety

The extension does not include analytics, remote executable code or its own trading API. Explicitly activating a native GMGN trading button can execute a real trade through GMGN. Review the privacy notice and source before installing.
