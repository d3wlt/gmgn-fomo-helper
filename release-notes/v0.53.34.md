# GMGN FOMO Helper v0.53.34

## Highlights
- FOMO Trending shows all supported tokens in the server list, independently of GMGN's chain selector or Link setting. Wallet Tracking continues to follow its native chain picker.
- Newly observed Trending entries display 🆕 for 10 seconds from receipt. Initial load, reconnect, Refresh and hidden-resume snapshots establish a baseline without badges. Rank and price changes do not restart the timer.
- Badge expiry removes only the marker, preserving hovered rows and list order. Narrow panels keep token names readable alongside the marker.
- Shorten the README to a feature-first overview with six screenshots. Installation, updating, diagnostics, limitations and development instructions are preserved in GUIDE.md.

## Installation
Download the release ZIP and SHA-256 checksum, verify the checksum, and extract to a permanent folder. Open chrome://extensions or edge://extensions, enable Developer mode, select Load unpacked and choose that folder.

## Usage
Sign in on FOMO, then select FOMO in GMGN's Trending panel. All supported chains remain visible regardless of the native picker; Wallet Tracking still uses its selected chains. The new-entry marker reflects membership observed during the current live connection, not a token's launch date or an all-time first appearance. Hovering, focusing or scrolling still holds list updates; a delayed row may appear after its badge has already expired.

## Updating
Replace the files in the existing unpacked extension folder, reload the extension, then refresh GMGN and FOMO once. Keep the same browser profile and extension identity to retain settings. Unpacked extensions do not update automatically from GitHub releases. See GUIDE.md in the repository for full setup and troubleshooting instructions.

## Security and privacy
No new permissions, provider requests, sockets or persistent storage are added by these changes. New-entry state is bounded, memory-only and cleared at connection/account boundaries. Screenshot samples are labelled; personal Following identities in reused live captures are redacted. Screenshots and documentation assets are not included in the runtime ZIP. Native QuickBuy can execute a real trade only when explicitly activated; no live trades were placed during verification. See PRIVACY.md for the full policy.
