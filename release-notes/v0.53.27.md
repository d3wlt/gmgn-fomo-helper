# GMGN FOMO Helper v0.53.27

## Highlights
- Fix FOMO Trending briefly appearing and disappearing after switching back to GMGN. Native FOMO suspends its subscription after three seconds hidden; the helper now retains the last validated snapshot instead of erasing it on unsubscribe.
- Preserve the original five-minute expiry and display the actual snapshot age. Acknowledgments do not make old data fresh.
- Retain bounded snapshots across suspended socket closure and require a fresh snapshot before accepting resumed/replacement-stream deltas. Logout, account changes and navigation still invalidate data.
- Add three genuine Chromium hidden/visible cycles with trusted local WebSocket frames, and harden disposable-browser cleanup.

## Installation
Download and extract the release ZIP. In `chrome://extensions`, enable Developer mode and load the extracted folder unpacked.

## Usage
Open Tokens → Trending in your existing signed-in FOMO tab, then select FOMO inside GMGN’s bottom-toolbar Trending panel. Switching back to GMGN now preserves the observed snapshot. Refresh reads already-observed worker memory; it does not ask FOMO for new data.

## Updating
Replace files in the existing unpacked extension folder and reload that extension to retain its identity and settings. Refresh both the FOMO and GMGN browser tabs afterward. Publishing this release does not automatically update unpacked installations.

## Security and privacy
No helper-created ranking requests, sockets, subscriptions or trades. Snapshot retention remains memory-only, account/document-bound and limited to five minutes from observation. Logout/account changes remain destructive invalidation boundaries. Native-view and mounted-price limitations remain unchanged.
