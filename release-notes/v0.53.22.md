# GMGN FOMO Helper v0.53.22

## Highlights
Remove the redundant purple THESIS position-action badge from thesis tracker rows in both card and table layouts. Keep the plain Thesis label and unrelated buy/sell position badges. README now describes current functionality instead of retired integrations.

## Installation
Extract gmgn-fomo-helper-v0.53.22.zip and load unpacked through chrome://extensions.

## Usage
Thesis rows show the plain Thesis label without the bordered position badge or inline narrative body. Token-panel content remains unchanged.

## Updating
Replace files in the existing extension folder, reload the extension and refresh GMGN and FOMO. No settings reset is needed.

## Security and privacy
No new permissions, requests or trading actions. Existing passive integration and bounded opt-in diagnostics remain unchanged. Private local diagnostics remain outside the package.
