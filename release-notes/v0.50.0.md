# better gmgn v0.50.0

## Highlights

- FOMO panels distinguish token-feed data from history reconstructed from current holders. Source, refresh time, partial coverage, and unavailable following information are visible.
- Partial holder-history results retain their completeness metadata through both cache layers and are not cached as authoritative snapshots.
- Followed-user tracker polling catches up through a bounded number of global activity pages, deduplicates overlapping events, and reports coverage gaps rather than silently implying a complete feed.
- Holders and Trades offer a Following-only view. Current holdings remain distinct from historical buys, trims, and exits. These are observations, not trading recommendations.
- Recoverable request errors display retry or reconnect guidance. Safe same-view data can remain visible with a stale warning; account, token, and tab changes discard it.
- Copy diagnostics exports only allowlisted operational metadata, not session credentials or raw account data.
- Added behavioral and real-Chromium fixture regressions, and made release-note validation tolerate historical notes.

## Installation

Verify the versioned ZIP against its SHA-256 checksum. Extract it to a permanent folder, enable Developer mode at `chrome://extensions`, then select **Load unpacked** and choose that folder.

## Usage

Sign in to FOMO in the browser. Open the FOMO panel on GMGN or DeBot and select **Holders** or **Trades**. Use **Following only** to narrow the loaded data to followed users. Read the source and coverage status before interpreting an empty or incomplete view.

Reconstructed trade history is limited to the returned current-holder sample, with a maximum of 50 trade histories. Fully exited users can be absent. A successful retrieval of this sample does not make it a complete token trading history. Following-only filtering narrows the loaded sample; it does not independently retrieve every followed account's lifetime trades.

Followed-feed catch-up is bounded. Initial startup, exhausted catch-up limits, failed pages, and uncertain continuity are reported as limited coverage. No lossless-history guarantee is made.

## Updating

Replace files in the existing unpacked-extension folder, select **Reload** in Chrome's extension manager, and refresh the GMGN and DeBot tabs. Unpacked extensions do not update automatically.

## Security and privacy

No wallet signing, transaction execution, analytics, or remote executable code is added. Existing session mirrors stay local and are used only for their supported service. Diagnostics are opt-in clipboard text and contain only version, chain, tab, status, source, timing, and coverage fields. Browser tests use synthetic fixtures and isolated profiles without reading the user's logged-in browser.
