# better gmgn v0.53.2

## Highlights

- Add off-by-default Debug logging, Export logs and Clear logs under popup Diagnostics; toggle changes save immediately.
- Local, bounded, persistent diagnostics: FOMO request categories/status/timing, missing-metadata counts and GMGN direct-Following received/eligible/placed counts. No raw response or console capture.
- Strict field allowlists exclude credentials, URLs, names, addresses, identifiers and thesis text at collection, restoration and export. No automatic upload.
- Logger writes do not trigger GMGN/DeBot settings rescans. Browser tests exercise real popup download/clear/disable and worker restart.
- Fix current market-cap enrichment not reaching tracker rows; label it as current token MC rather than historical trade-time MC.
- Include provider-timestamped recent token theses on first load instead of suppressing them as notification baselines.

This is not a claim of complete parity with native FOMO Alerts. Missing-profile/amount differences and upstream coverage still require signed-in diagnostics.

## Installation

Extract the runtime ZIP to a permanent folder. Open `chrome://extensions`, enable Developer mode and choose Load unpacked. Chrome 116+ is required.

## Usage

Enable Diagnostics → Debug logging, reproduce the issue, then Export logs. Send the JSON with a screenshot and approximate issue time. Disable logging afterwards. Existing logs can be exported while disabled; Clear logs removes saved history but not previously downloaded files.

Up to 500 records from the previous 24 hours are retained locally and pruned on use. Writes are batched; an abrupt browser shutdown can lose the final unsaved records. Logging is targeted feed diagnostics, not a complete raw network trace.

## Updating

Replace the unpacked files, click Reload on the extension card and refresh GMGN. Unpacked extensions do not auto-update.

## Security and privacy

No new permissions, telemetry, automatic upload, bot credentials or transaction execution. Export is initiated only from the extension popup. The ZIP excludes tests, screenshots and logs. The running Fomo bot is unchanged. Synthetic tests do not establish authenticated provider completeness.
