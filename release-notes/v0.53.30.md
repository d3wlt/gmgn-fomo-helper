# GMGN FOMO Helper v0.53.30

## Highlights
- Preserve the selected FOMO Trending source across same-tab reloads and browser tab discards within the current browser session. Blank header clicks and non-tab controls no longer deselect FOMO. Explicit native selection, close, disable and account invalidation still clear the preference.
- Recognize Arc mainnet (FOMO network 5042) across Following activity, token context and Trending. Arc rows display the blue or custom chain stripe and navigate to `gmgn.ai/arc/token/<contract>`. Identical contract addresses on other chains remain separate.
- Add regression coverage for Arc rendering/navigation, native visibility, worker restart, tab discard and delayed selection/account-reset races. Browser fixtures use synthetic data; no live trades are executed.

## Installation
Download the release ZIP and SHA-256 checksum, verify the checksum, and extract the ZIP to a permanent folder. Open `chrome://extensions` or `edge://extensions`, enable Developer mode, select Load unpacked, and choose that folder.

## Usage
Select FOMO in GMGN's bottom-toolbar Trending panel for automatic updates while the panel is visible. Returning after a reload restores the selected source; reconnecting can still briefly show a connection/loading state. Arc activity uses its own chain color and token route. Following remains passive and requires an existing signed-in FOMO tab receiving native activity.

## Updating
Replace the files in the existing unpacked extension folder, reload the extension, then refresh GMGN and FOMO once. Keep the existing browser profile and extension identity to retain settings. Unpacked extensions do not automatically update from GitHub releases.

## Security and privacy
No new permissions or trading paths are added. Arc QuickBuy remains unavailable. Hidden or closed panels still release live demand. Only bounded tab-selection preferences persist in extension-only session storage; ranking data and credentials are not stored in those preferences. Existing session requirements, account-reset behavior and passive Following boundaries remain unchanged. See PRIVACY.md for the full data-handling policy.
