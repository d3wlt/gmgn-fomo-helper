# better gmgn v0.53.10

## Highlights
- Exclude native TrackerListItem cards and their metric rows from Flap auto-height CSS.
- Preserve GMGN native fixed virtualizer row geometry even when a recycled card retains the Flap marker. No merged-scroll redesign or forced global row height.
- Regression reproduces the old 41px card inside a 64.5px slot, then verifies matching height with marker toggles and narrow widths. Non-native Flap auto-sizing remains unchanged.

## Installation
Extract ZIP, enable Developer mode and Load unpacked at chrome://extensions.

## Usage
Native tracker cards keep the height assigned by GMGN. Existing feed, quick buy and developer stats remain unchanged.

## Updating
Replace files, reload the extension and refresh GMGN/FOMO tabs.

## Security and privacy
CSS-only runtime change. No network, trading, permissions, credentials or CSP changes.
