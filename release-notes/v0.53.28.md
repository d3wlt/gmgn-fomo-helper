# GMGN FOMO Helper v0.53.28

## Highlights
- FOMO Trending updates automatically through one shared authenticated connection while a visible GMGN Trending panel has FOMO selected. No routine Refresh or return to FOMO's Trending view is required.
- Preserve FOMO selection during token navigation and same-account credential rotation. Hold displayed rows during hover, keyboard focus and scrolling.
- Release demand immediately when hidden or closed; recover from connection loss and worker restart with a fresh snapshot. Clear invalid session data immediately and prevent logout resurrection.
- Preserve server ordering, exact chain/address identity and unknown metrics. Keep Following passive and unchanged.

## Installation
Download and extract the release ZIP. In `chrome://extensions`, enable Developer mode and load the extracted folder unpacked.

## Usage
Sign in on FOMO, then select FOMO inside GMGN's bottom-toolbar Trending panel. Live updates run automatically while selected and visible. Refresh is a reconnect fallback. Native-page hidden-token filters and chart-price overrides are not applied to this independently advancing stream.

## Updating
Replace the files in your existing unpacked extension folder and reload the extension to retain its identity and settings. Refresh the FOMO and GMGN tabs once after upgrading. GitHub publication does not auto-update unpacked installations.

## Security and privacy
Only Trending uses the new authenticated socket. The worker validates current documents using webNavigation and performs bounded account/restriction verification against FOMO. Tokens are not exposed in panel messages. Logout revocation survives worker restart. No ranking REST fallback, extra Following subscriptions, automatic keeper creation, FOMO activation/reloads or refresh-token exchange is added. A valid native session is required; indefinite page-free renewal is not guaranteed. No trades or settings resets were performed during verification.

Verification covered the full local regression gate, actual MV3 hidden/multi-window/connection-loss/restart/logout behavior, and a source-stable 15-minute live run with native Trending unsubscribed and continuous GMGN updates. Shared live Chrome reported FOMO visible; genuine hidden-document behavior was separately verified in isolated Chromium.
