# GMGN FOMO Helper v0.53.23

## Highlights
Restore actual thesis post text in both tracker layouts while retaining the plain Thesis label and removing redundant thesis badges. Local English translation remains available where supported.

Align default FOMO header padding, timestamp inset and MC typography more closely with native GMGN without changing colors. Buy/Sell and MORE/PARTIAL remain together; narrow rows adapt ticker placement. Native recycler row heights are unchanged; thesis bodies retain variable-height layout.

Fix native QuickBuy context discovery for table rows. Retain token/account/committed-context/gesture guards and expose more specific unavailable explanations. Hover controls temporarily replace adjacent metadata instead of overlapping it.

## Installation
Extract gmgn-fomo-helper-v0.53.23.zip and load unpacked through chrome://extensions.

## Usage
Thesis rows show the actual post text. Hover supported FOMO rows for native QuickBuy using GMGN's own Following settings. An unavailable control remains disabled; the helper does not supply a trade amount or bypass safety guards.

## Updating
Replace files in the existing extension folder, reload the extension, and refresh GMGN and FOMO. No settings reset is needed.

## Verification boundaries
Automated production-source Chromium/MV3 tests cover thesis rendering, translation fixtures, native card/table context discovery, header geometry and merged scrolling. Real signed-in execution and the exact cause of the reported LOTTO state remain unverified. No trades were placed. Custom native column layouts are not mirrored; narrow layouts prioritize readability.

## Security and privacy
No new permissions or independent feed polling. Native Buy can execute a real trade only when activated. Private diagnostics remain excluded from the package.
