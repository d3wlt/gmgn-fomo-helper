# better gmgn v0.53.1

## Highlights

- Follow-up to the Fomobot-derived direct Following collector port in v0.53.0.
- Recover missing token symbols with bounded, chain/address-validated metadata; blank enrichment must not erase a known ticker.
- Recover missing profiles from owner-checked trade details, including sellers absent from current-holder lists.
- Revisit retained events after transient enrichment failures, with bounded retries and account-isolated caches.
- Fix cached tracker cards ignoring later name/ticker/avatar/amount/comment changes. Unchanged snapshots keep their DOM; enrichment does not duplicate or re-animate a trade.
- Show an explicit user-ID/token-address fallback when real metadata remains unavailable; never invent names or tickers.

## Installation

Extract the runtime ZIP to a permanent folder. Open `chrome://extensions`, enable Developer mode, choose Load unpacked and select the folder. Chrome 116+ is required.

## Usage

Sign in to FOMO in the same browser profile and enable the FOMO feed in the GMGN tracker. Direct Following uses your FOMO following list, not the Telegram bot roster. Existing event, chain and token filters remain effective.

This is bounded polling and recovery, not guaranteed complete or real-time provider coverage. Synthetic browser and MV3 tests verify implementation behavior, not authenticated live-account delivery.

## Updating

Replace the unpacked files, click Reload on the extension card, and refresh GMGN. Unpacked extensions do not auto-update. This local package does not alter the running Fomo bot or your browser profile.

## Security and privacy

No new host permissions, bot credentials, Telegram delivery, wallet signing or trading execution. Enrichment uses the existing browser-local FOMO session and exact provider identities. Tests and screenshots are excluded from the runtime-only ZIP.
