# better gmgn v0.47.1

## Highlights

This patch fixes malformed wallet-tracker rows caused by GMGN's transform-positioned virtual list while preserving the English-only, manual ZIP release model introduced in v0.47.0.

- Wallet-tracker rows retain GMGN's native vertical positioning instead of collapsing on top of each other.
- FOMO and Pump insertions use an independent CSS offset that does not overwrite the site's transform.
- Row geometry works with both transform-positioned and top-positioned tracker layouts.
- Regression coverage verifies that native transforms survive insertion and cleanup.

## Installation

Download the ZIP and matching checksum from this repository's GitHub Release. Verify the checksum, extract the archive to a permanent folder, enable Developer mode at `chrome://extensions` or `edge://extensions`, select **Load unpacked**, and choose the extracted folder.

## Usage

Open GMGN's wallet tracker normally. FOMO and Pump activity can be interleaved with native tracker rows without changing the site's own row positioning. Other extension features and settings continue to work as documented in the README.

## Updating

Replace the files in the existing unpacked-extension folder with this release, then select **Reload** on the extension card. Refresh the GMGN tab afterward so its virtual tracker list is recreated cleanly.

## Security and privacy

The extension contains no analytics, remote executable code, wallet signing, or transaction execution. Supported-site sessions and settings remain in browser-local extension storage and are used only for the documented site integrations. This project is independent and is not affiliated with the supported services or the original upstream author.
