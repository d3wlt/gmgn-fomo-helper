# better gmgn v0.53.6

## Highlights

One chronological tracker.

- Replace the separate capped FOMO pane with one chronologically interleaved GMGN/FOMO scrolling surface.
- Map merged scroll coordinates back to the native virtualizer; preserve original native cards and handlers.
- Read the observed native timestamp index through the production page bridge; require validated uniform rows and full descending timestamp index. Unsupported/untimed layouts preserve native rows but do not inject FOMO cards.
- Preserve fractional native row heights (including GMGN's live 64.5px rows).
- Regression: 100 native plus 40 FOMO reachable with chronological ordering, no overlap, recycling/arrivals, native click handlers, responsive sizing, teardown; fractional-height and unsupported-layout cases.
- Live Chrome check: merged surface with 25 FOMO cards; scroll beyond FOMO confirmed 9 native cards visible and no nested scrollbars. This is not a long-duration live-arrival soak test.
- Passive FOMO collection remains unchanged; no independent provider subscription added.

## Installation
Extract the ZIP, enable Developer mode at chrome://extensions, and Load unpacked from the extracted folder.

## Usage
Keep a signed-in native FOMO Alerts tab open. Supported GMGN tracker layouts interleave native and FOMO activity by time in one scroll area.

## Updating
Replace the previous extracted files, reload the extension, then refresh GMGN and FOMO tabs. Unpacked extensions do not auto-update.

## Security and privacy
No trading actions are added or executed. Passive Following observation adds no independent provider connections. Credentials remain browser-local. The native index exports timestamps only; unsupported layouts preserve native rows rather than fabricating history.
