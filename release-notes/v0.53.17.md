# GMGN FOMO Helper v0.53.17

## Highlights
Diagnostic build for intermittent tracker blinking. Adds opt-in surface creation/destruction IDs, validation deferrals/failures/recovery reasons, visible/attached card counts, and outer/native scroll coordinates. Lifecycle events bypass the existing five-second render sampler; scroll samples are limited to four per second. This is instrumentation, not a claimed blinking fix.

## Installation
Extract gmgn-fomo-helper-v0.53.17.zip into the existing unpacked extension folder, reload at chrome://extensions, and refresh GMGN and the signed-in FOMO tab.

## Usage
Enable Diagnostics > Debug logging. Clear previous logs, reproduce blinking for 20–30 seconds, export immediately, and disable logging. Send the JSON export, not cookies or a network HAR.

## Updating
The extension key is unchanged. Chromium does not automatically update unpacked extensions. Preserve your existing extension folder and settings.

## Security and privacy
Diagnostics remain opt-in and local-only, limited to 500 entries over 24 hours. New data is restricted to numeric geometry/counts and fixed event/reason enums; no wallet addresses, trade identifiers, DOM text, credentials or raw errors are exported. No feed requests or trading actions are added. Native QuickBuy can execute a real trade only when activated.
