# better gmgn v0.53.3

## Highlights

This update targets the source-contract gaps found after v0.53.2. Public production bundle evidence is preserved in `docs/fomo-native-alerts-contract.md`; synthetic tests are not evidence of authenticated account completeness.

- Native `/feed/tradingActivity` collection with bounded pagination and gap reporting, rather than treating social `/feed` as native Alerts.
- Native amount and FDV/market-cap provenance, user identity/avatar and thesis normalization.
- Following-profile roster and direct user-ID recovery; corrected `lastSwapIdV2` swap cursor.
- Structured pagination diagnostics: endpoint category, pages, received items, has-more, cursor-advancement and stop reason. No raw cursor, user ID or URL is logged.
- Successful requests coalesce into ten-second endpoint/status buckets. `count` is the number of requests; `durationMs` is their maximum duration. Failures remain individual records.

## Diagnostic evidence

The supplied v0.53.2 export contained 500 records spanning 127.243 seconds. All 463 request records were categorized successful, yet all 13 completed collector records had 472 missing profiles among 500 retained events. Each of the 24 renderer records placed every eligible row. This points to collection/profile enrichment gaps; it does not prove that every expected upstream event was fetched or displayed.

Replaying that export through the new logger retained 128 records while representing all 463 requests and 13 collector summaries, with no new capacity drops.

## Scope limits

This version polls native Alerts; it does not connect the native `trading_activity` live subscription. Individual buys, sells and theses are supported. Transfers and grouped multi-user Alerts are not directly rendered; unsupported native rows are counted, trigger fallback collection and keep coverage partial. No authenticated live-account parity claim is made.

## Installation

Extract the runtime ZIP to a permanent folder. In `chrome://extensions`, enable Developer mode and Load unpacked. Chrome 116+ is required.

## Updating

Unpacked extensions do not auto-update.

## Usage

Replace the unpacked extension files, Reload in `chrome://extensions`, then refresh GMGN. Enable Diagnostics → Debug logging, reproduce the issue, and Export logs. Send the JSON with a screenshot and approximate issue time. Turn logging off afterwards.

## Security and privacy

No new permissions, automatic uploads or transaction execution. Credentials, raw payloads, cursor values, names and addresses remain excluded from diagnostic exports. The running Fomo bot is unchanged.
