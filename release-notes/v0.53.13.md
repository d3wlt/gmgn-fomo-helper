# better gmgn v0.53.13

## Highlights

### Tracker scrolling
- Keep native GMGN rows visible during fractional, in-place virtual-row recycling.
- Preserve the single merged GMGN + FOMO panel through a bounded metadata handoff instead of rebuilding it at scrollTop 0.
- Preserve the reading position during new activity below the top, and clean up wheel listeners on teardown.
- Unknown layouts and persistently stale metadata still fail closed.

## Token-page followed holders
- Move followed-holder counts off token lists and tracker cards onto the open token page's bottom-right FOMO button.
- Request only that token and its exact chain, at most once per minute after successful lookups while the page is visible; failures retain bounded backoff.
- Parse FOMO's responseObject.tokens response and distinguish confirmed zero from unavailable data. Hover shows returned usernames.

## Hybrid holdings and Robinhood
- Capture native hybrid multichain and legacy single-chain holding requests for fresh ownership confirmation.
- Support Robinhood position alerts while respecting explicit native disabled settings, selected-wallet boundaries, account changes, positive balances and valid costs.
- Restore native Robinhood QuickBuy on large Fusion pages without weakening account/token guards.

## Removed features
- Remove extension manifesto pop-ups/list tab, Flap tax badges and custom BSC RPC configuration and permission requests.
- Preserve native GMGN content and shared token-supply lookup. No exchange-listing integration is included.

## Verification
- Full npm run verify passed, including expanded asynchronous virtual-row recycling and MV3 browser regressions.
- Live GMGN scrolling down to the bottom and back up showed no missing expected native rows or panel resets; mouse-wheel scrolling also passed.
- Hybrid holding discovery/price polling, native QuickBuy rendering and token-page holder counts were checked live. No live trades were executed and no natural surge alert was triggered for testing.

## Installation
Download the extension ZIP, extract it and load or reload the folder through chrome://extensions with Developer mode enabled. Refresh GMGN and the existing signed-in FOMO tab after reloading the extension so the passive source reconnects. Chrome does not auto-update unpacked extensions.

## Usage

Open the native Holding panel to initialize the selected wallets. Position alerts require a visible GMGN page and recent captured native request scopes; expired scopes fail closed. The FOMO feed remains passive: no independent feed polling or sockets were added.

## Updating

Replace the unpacked extension folder with this release, reload it in chrome://extensions, then refresh GMGN and the existing signed-in FOMO tab. Preserve your browser profile and extension settings.

## Security and privacy

The package contains only allowlisted extension runtime files, not browser profiles, credentials, test fixtures or local diagnostics. Native trading controls retain account/token guards; this release does not execute trades automatically. The repository remains private.
