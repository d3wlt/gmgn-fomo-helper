# GMGN FOMO Helper v0.53.19

## Highlights
Healthy status now reads FOMO connected. Coverage limitations remain in the tooltip and diagnostics, not the persistent label. Disconnected/setup states use red styling and profile/sign-in/Alerts recovery guidance. Position the badge above GMGN's bottom toolbar and adapt to viewport resizing.

Special-wallet watch is retired completely, including the ★ count bar, wallet/address/tracker stars, color picker/highlights, add-wallet watch checkbox and pinned activity. Old saved watch settings no longer do anything. Watched developer tracking, callout-account blocklists, token holder rankings, position-surge alerts and the independent native cross-chain wallet-follow shortcut remain.

Tracker token blocking is also removed. Notification history stays beside its bell and clears without a confirmation dialog.

The holders panel now uses one vertical scrolling region without horizontal overflow. Full holder names wrap above their badges. The EN toggle is removed; English translation stays enabled where the browser-local translation API and language packs are available.

FOMO tracker names retain full two-line display where they fit. Overflowing names receive a Unicode-safe `...` suffix and a full-name tooltip on hover or keyboard focus. Native recycler row heights remain unchanged.

## Installation
Extract gmgn-fomo-helper-v0.53.19.zip, load unpacked through chrome://extensions, and refresh GMGN and the signed-in FOMO tab.

## Usage
Hover the status badge for coverage details. Follow red guidance to initialize the native FOMO profile/Alerts feed. Connected is not a guarantee of complete historical coverage.

## Updating
Replace files in the existing extension folder, reload the extension, and refresh both sites. The extension key and settings identity are unchanged.

## Security and privacy
No added permissions, source polling or trade execution. Native QuickBuy can execute a real trade only when activated. Existing opt-in local diagnostics retain their numeric/enum allowlist and bounded retention.
