# better gmgn v0.50.1

## Highlights

- FOMO-injected rows in the GMGN wallet tracker now refresh their relative age every second, matching native GMGN rows: `1s`, `2s`, `3s`, then minutes, hours, and days.
- Both compact cards and table-layout rows carry their source timestamp and update while the tab is visible.
- A real-Chromium regression verifies that a FOMO table row advances automatically rather than remaining stuck at its first rendered age.

## Installation

Verify the versioned ZIP against its SHA-256 checksum. Extract it to a permanent folder, enable Developer mode at `chrome://extensions`, then select **Load unpacked** and choose that folder.

## Usage

Open GMGN's wallet tracker with FOMO activity enabled. FOMO-injected row ages now advance alongside native tracker rows while the tab is visible.

## Updating

Replace files in the existing unpacked-extension folder, select **Reload** in Chrome's extension manager, and refresh the GMGN tabs. Unpacked extensions do not update automatically.

## Security and privacy

This patch changes only client-side relative-time rendering and its browser regression. It adds no wallet signing, transaction execution, analytics, remote executable code, or new network access.
