# GMGN FOMO Helper v0.53.20

## Highlights
Fix ordinary FOMO tracker usernames being replaced by dots under font/zoom geometry differences. Full source names stay intact; CSS handles exceptional overflow and full-name tooltips remain available on hover or keyboard focus. Native tracker row heights and actions are unchanged.

## Verification
Production-source browser regressions cover real Geist font metrics, zoom, delayed font loading, height recovery and tooltips. The signed-in user setup still needs confirmation after updating.

## Installation and updating
Extract gmgn-fomo-helper-v0.53.20.zip into the existing extension folder, reload through chrome://extensions, and refresh GMGN and FOMO. Keep the same folder to retain extension identity/settings.

## Updating
Replace files in the existing extension folder, reload the extension and refresh both tabs. No settings reset is required.

## Usage
Normal trader names are visible in the row; hover or focus exceptionally long names for the full name.

## Security and privacy
No new permissions, polling or trading actions. Existing passive FOMO integration and bounded opt-in diagnostics remain unchanged. Test fonts and private diagnostics are excluded from the extension package.
