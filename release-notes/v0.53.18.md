# GMGN FOMO Helper v0.53.18

## Highlights
Remove the compact-row followed star and reclaim name space; format large market caps using B/T suffixes instead of oversized M values.
Fix fractional translation readback: CSSOM rounds values, so the extension must compare against the browser-serialized applied shift, not its higher-precision input. A reproduced mismatch incorrectly treated a native row at 90px as 161.33px and could destroy/rebuild the merged tracker. Actual Chromium regression fails before and passes after the fix. User-side confirmation is pending; diagnostics are retained.

## Installation
Extract gmgn-fomo-helper-v0.53.18.zip into the existing unpacked extension folder, reload at chrome://extensions, and refresh GMGN and FOMO.

## Usage
Enable Diagnostics > Debug logging, clear old logs, reproduce normal scrolling for 20–30 seconds, export immediately and disable logging. Send the JSON even if blinking stops, to confirm the rebuild loop is gone.

## Updating
Extension identity and settings are preserved. Chromium does not automatically update unpacked extensions.

## Security and privacy
No new feed requests, permissions or trading actions. Native QuickBuy can execute a real trade only when activated. Diagnostics remain opt-in, local and restricted to fixed enums and numeric counts/geometry, capped at 500 entries over 24 hours. Do not send cookies, browser storage or HAR exports.
