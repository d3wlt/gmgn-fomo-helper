# GMGN FOMO Helper v0.53.16

## Highlights
- Fix recurring merged-tracker scrolling and disappearing FOMO cards: committed React metadata, native liquidity rows, stable identity anchors, viewport-independent dedup and logical scroll bounds.
- Remove the separate 40-card render cap; display eligible events from the already-bounded passive snapshot (up to 500 retained events).
- Restore native recycler parentage before card/list switches to prevent React unmount crashes.
- Dismiss position-surge toasts after five seconds even while hovered; remove the trailing dollar token price while preserving Cost/5m metrics, token action and history.
- Move FOMO and its holder count to the token-information header; move notifications to the end of GMGN's main navigation. Remove floating launchers.

## Verification
- Full local npm run verify passed before release preparation.
- Live card/list down/up and idle checks covered 132 samples with retained surfaces and visible-card anchors, including incoming activity. Repeated layout switching completed without page errors.
- Added committed-tree, liquidity-row, native-unmount, burst/eviction, toast-lifetime and launcher-remount regressions.
- No live trades or artificial market events were executed. Passive source coverage remains bounded, not lifetime history.

## Installation
Download gmgn-fomo-helper-v0.53.16.zip and its .sha256 checksum from this private release. Verify the checksum, extract to a permanent folder, enable Developer mode at chrome://extensions and select Load unpacked.

## Usage
Keep your existing signed-in FOMO tab receiving native Alerts activity; open your FOMO profile if the following roster has not initialized. Use the FOMO header button for token context and the main-menu bell for notification history. Open GMGN's native Holding panel to initialize position monitoring.

## Updating
Replace the files in the existing unpacked extension folder, reload the extension, and refresh GMGN and the existing signed-in FOMO tab. The extension key and settings identity are unchanged. Chromium does not automatically update unpacked extensions.

## Security and privacy
The repository remains private. Packages contain only allowlisted runtime files, excluding credentials, browser profiles, tests and local diagnostics. Following activity remains passive; token panels and holder counts retain scoped requests. Native QuickBuy can execute a real trade only when activated; account, chain and token guards are preserved. J7Tracker and DeBot remain removed.
