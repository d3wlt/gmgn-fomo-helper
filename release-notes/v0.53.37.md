# GMGN FOMO Helper v0.53.37

## Highlights
- Extend the approved black, grey-outline FOMO eyes + Trending badge to native token-page headers.
- Show existing confirmed members immediately and automatically add/remove the badge when the viewed token enters/exits the latest received Trending snapshot, even while the Trending list is held.
- Match chain and full contract, preserving Solana case; require route, native header CA and chain-specific explorer agreement during navigation. Preserve native geometry and omit unknown or cramped layouts.
- Retain Migrated-card badges, violet new-entry highlights and sorted chain counts.

## Usage
Sign in on FOMO and keep FOMO selected in GMGN's visible Trending panel. Both token-header and Migrated badges reuse that live feed; neither runs independent background collection. Badges clear when membership exits or data expires, and at lifecycle resets. They indicate current observed membership, not a trading recommendation.

## Installation
Download the ZIP and SHA-256 checksum, verify and extract to a permanent folder. Open chrome://extensions, enable Developer mode and Load unpacked. See GUIDE.md for full instructions.

## Updating
Replace the existing unpacked files, reload the extension, then refresh GMGN and FOMO. Keep the same browser profile and extension identity to preserve settings. GitHub releases do not automatically update unpacked extensions.

## Security and privacy
No new provider requests, sockets, demand, permissions or persistence. Uses the already-bundled official eyes image and isolated-world validated feed. Native trading controls are unchanged; no live trades were placed during testing.
