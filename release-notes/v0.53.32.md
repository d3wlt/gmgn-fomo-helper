# GMGN FOMO Helper v0.53.32

## Highlights
- Add FOMO Thesis after X Tracker inside GMGN Community: a compact native-style list with full text, author names, timestamps and read-only likes.
- Load token-and-chain-scoped history and native updates on demand, independently of chart-bubble visibility. Preserve native Callout/X Tracker and resizing, support narrow panels, and retain reading position as updates arrive.
- Retain up to 200 newest received posts in page memory. Coverage is limited, not guaranteed all-time history. Refresh is manual and rate-limited; partial failures remain visible rather than masquerading as an empty feed.
- Enable Arc QuickBuy through GMGN's native component, preserving account, token, trusted-input and stale-context safety guards. GMGN controls wallet eligibility; Arc does not support native browser-plugin wallet mode.

## Installation
Download the release ZIP and SHA-256 checksum, verify the checksum, and extract to a permanent folder. Open chrome://extensions or edge://extensions, enable Developer mode, select Load unpacked and choose that folder.

## Usage
Open a token page, select GMGN Community, then FOMO Thesis. Chart thesis bubbles can remain off. The feed stops when hidden or closed and clears on token/account boundaries. Likes are display-only; no posting or liking action is added. Arc QuickBuy uses native Following settings and the USDC quote.

## Updating
Replace the files in the existing unpacked extension folder, reload the extension, then refresh GMGN and FOMO once. Keep the existing browser profile and extension identity to retain settings. Unpacked extensions do not update automatically from GitHub releases.

## Security and privacy
No new extension permissions. Thesis requests use GMGN's native API and stream only while the feed is demanded; no always-running history collector or credential persistence is added. Account/auth boundaries stop and clear the feed. Live thesis verification used a temporary tab; Arc verification rendered the native control without executing a trade. See PRIVACY.md for the full policy.
