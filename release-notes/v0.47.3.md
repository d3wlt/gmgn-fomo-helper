# better gmgn v0.47.3

## Highlights

This patch completes the developer-performance tooltip lifecycle fix after an independent review of v0.47.2. It preserves the wallet-tracker layout correction from v0.47.1 and the English-only, manual ZIP release model introduced in v0.47.0.

- Click suppression follows the clicked watched card, including same-card DOM replacement, without suppressing a different watched card entered directly afterward.
- Active tooltips are dismissed on scroll, window blur, hidden-tab transitions, and active-card removal.
- Pointer movement can restore a tooltip normally after lifecycle dismissal without weakening click suppression.
- Regression and real-browser coverage exercise direct card-to-card movement, DOM replacement, scrolling, blur, tab visibility, and card removal.

## Installation

Download the ZIP and matching checksum from this repository's GitHub Release. Verify the checksum, extract the archive to a permanent folder, enable Developer mode at `chrome://extensions` or `edge://extensions`, select **Load unpacked**, and choose the extracted folder.

## Usage

Open GMGN normally. Hovering a watched developer card shows the full developer-performance details. Clicking the card or its chart dismisses the details for that card until the pointer leaves it, while moving directly to another watched card shows the new card's details. Scrolling, switching away, or GMGN replacing/removing the card also dismisses stale details. Wallet-tracker FOMO and Pump insertions continue to preserve GMGN's own row positioning.

## Updating

Replace the files in the existing unpacked-extension folder with this release, then select **Reload** on the extension card. Refresh the GMGN tab afterward so its virtual tracker list is recreated cleanly.

## Security and privacy

The extension contains no analytics, remote executable code, wallet signing, or transaction execution. Supported-site sessions and settings remain in browser-local extension storage and are used only for the documented site integrations. This project is independent and is not affiliated with the supported services or the original upstream author.
