# better gmgn v0.53.7

## Highlights
- Native GMGN QuickBuy on FOMO Following tracker cards, visible on hover/focus.
- Mount the actual native component with explicit chain/address/symbol/logo and buyType follow. Never clone a donor callback; GMGN owns wallet selection, amount settings, confirmations and execution.
- Supported adapter identities: SOL, ETH, BSC, Base. Other chains, invalid identity, removed/recycled cards and unavailable native context fail closed.
- Snapshot current native React providers and block stale-context gestures. No scripted clicks accepted. One active native root; cleanup on card removal/change and page exit.
- Existing single chronological native/FOMO feed and passive collection unchanged.

## Installation
Extract the ZIP, enable Developer mode at chrome://extensions, and Load unpacked from the extracted folder.

## Usage
Keep signed-in GMGN and native FOMO Alerts tabs open. Hover a Following notification, then its Buy control. It uses GMGN Following settings; inspect your wallet, chain and amount before clicking. A click may immediately execute a real trade, depending on native settings. Buy unavailable means the adapter could not safely mount; open the token page normally instead.

## Updating
Replace prior extracted files, reload the extension, then refresh GMGN and FOMO. The native adapter pins the observed GMGN module contract and may need updating when GMGN deploys changes.

## Security and privacy
No helper trading endpoint, copied trade callback, extracted credential or autonomous purchase. Real financial controls were not clicked during validation. Offline synthetic handlers verify identity, current amount, no navigation/duplicate click action, and stale-context/untrusted-input blocking. Live signed-in Chrome verified native component rendering and exact FOMO chain/token props, not a completed trade. Passive FOMO collection remains unchanged.
