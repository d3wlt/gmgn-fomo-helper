# better gmgn v0.53.5

## Highlights

- Fix native GMGN tracker notifications disappearing below FOMO bursts. Extension activity now lives in an independently scrolling lane above the native viewport, outside GMGN's virtual spacer.
- Keep all 40 eligible recent events reachable; no reduced head/inline placement caps. Native row transforms, offsets and scroll extent are not changed by FOMO activity.
- Keep the lane through empty native trackers, row recycling and tracker remounts. Preserve card identity, metadata refresh, filtering, transaction deduplication and native token-block collapse.
- Direct Following remains passive native-tab observation: no independent FOMO sockets, polling or catch-up requests.

## Installation

Extract to a permanent folder. Open `chrome://extensions`, enable Developer mode and Load unpacked. Chrome 116+ required.

## Updating

Replace unpacked files and Reload the extension, then refresh GMGN and FOMO. Unpacked extensions do not auto-update.

## Usage

Scroll the FOMO / Pump activity lane separately from native GMGN notifications. The lane uses at most 220px or 28% of viewport height, leaving the native list below it; it is removed when empty or disabled. The existing latest-40-event display bound is unchanged, not a lifetime-history guarantee.

Keep a signed-in FOMO Alerts tab open for passive Following delivery. Only data received by the website is observed. Missing history is not independently fetched, and worker/browser restarts may discard the memory-only passive cache. Optional token panels and J7Tracker remain separate integrations.

## Security and privacy

No new permissions, remote hosts, trading or transaction execution. No new provider traffic, sockets or credential handling. Tests use isolated synthetic Chromium fixtures; this release does not claim authenticated live-account completeness.
