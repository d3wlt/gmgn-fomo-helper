# GMGN FOMO Helper v0.53.36

## Highlights
- New Trending entries receive a subtle violet tint and inset outline alongside 🆕. Both expire on the existing 10-second receipt timer, without flashing or moving held rows.
- Compact per-chain counts appear below the live status, sorted largest first with zero counts omitted. Counts reflect the displayed list, including hover-held snapshots.
- Native Migrated cards show a black, fine-grey-outline badge with official white FOMO eyes and Trending when chain plus full contract matches current received Trending membership. Solana matching remains case-sensitive; tickers are never used.

## Limitations
The Migrated badge requires FOMO Trending selected and visible. It uses the existing live snapshot, including baseline members, not an independent background feed. Badges clear on removal, stale data and lifecycle resets; narrow cards omit the badge rather than cover native controls. This is membership evidence, not a trading recommendation.

## Usage
Sign in on FOMO and select FOMO in GMGN's visible Trending panel. Counts appear below the live status; newly arriving rows highlight for 10 seconds. Matching native Migrated cards show the badge when space permits.

## Updating
Replace the existing unpacked files, reload the extension, then refresh GMGN and FOMO. Keep the same profile and extension identity to preserve settings.

## Installation
Download the ZIP and SHA-256 checksum, verify and extract to a permanent folder. Load unpacked from chrome://extensions with Developer mode enabled. Existing users should replace files, reload the extension, then refresh GMGN and FOMO. GitHub releases do not automatically update unpacked installations. See GUIDE.md for full instructions.

## Security and privacy
No additional provider requests, sockets, collection demand or persistent storage. The official logo is bundled locally and exposed only to GMGN through a scoped web-accessible resource. Native trading controls remain unchanged; no live trades were placed during verification.
