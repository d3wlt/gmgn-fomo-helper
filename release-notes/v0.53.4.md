# better gmgn v0.53.4

## Highlights

- Direct Following switches to passive native-tab observation: reuse Alerts data already received by the signed-in FOMO website.
- No direct-feed API polling, independent socket, subscription, network heartbeat or automatic catch-up request.
- Explicit waiting/connected/disconnected tracker status. Local bridge liveness messages do not contact FOMO.
- Remove automatic FOMO keeper-tab activity and early restoration of stored credentials into the website. Closing FOMO does not cause the helper to reopen it.
- Retain native field normalization, bounded deduplication and metadata-aware smooth rendering. No additional profile or token recovery requests in this mode.
- Add sanitized passive connection/activity diagnostics.

## Installation

Extract to a permanent folder. Open `chrome://extensions`, enable Developer mode and Load unpacked. Chrome 116+ required.

## Updating

Replace unpacked files and Reload the extension. Refresh both FOMO and GMGN. Unpacked extensions do not auto-update.

## Usage

Keep one signed-in FOMO tab open with Alerts selected; the first active document owns the passive feed. The helper observes only what the website itself receives. If waiting for the native following list persists, open the following list on FOMO or refresh the page; the helper does not fetch it independently. Closing/suspending/signing out stops delivery. Reconnection can reuse history FOMO itself loads, but missing events are not guaranteed to be recovered.

The passive event cache is memory-only. Worker/browser restarts can discard old rows; only subsequent native observations refill it. Refresh FOMO if native history or session binding needs to be observed again. No hidden REST recovery runs.

Enable Diagnostics → Debug logging when reproducing a problem, then Export logs with a screenshot. Disable logging afterwards.

## Security and privacy

No new remote host or transaction execution. No socket authentication or raw credentials are forwarded by the passive bridge. The signed-in FOMO page remains a trust boundary: this does not guarantee permission under FOMO terms or immunity from account restrictions.

Scope is the direct Following tracker. Existing optional token panels and the separate J7Tracker integration remain separate features and may still make their own requests. No authenticated live-account completeness claim. Grouped/transfer Alerts and rich thesis presentation remain outside this update.
