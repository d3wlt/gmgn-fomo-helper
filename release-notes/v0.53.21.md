# GMGN FOMO Helper v0.53.21

## Highlights
Tracker events now say Thesis instead of Narrative. Inline thesis text and redundant tokenless THESIS placeholders are removed in card and table layouts. Real addressed token symbols, including tokens named THESIS, retain their identity/actions. Token-panel thesis content remains unchanged.

## Installation
Extract gmgn-fomo-helper-v0.53.21.zip and load unpacked through chrome://extensions.

## Usage
Thesis events retain trader/profile information and meaningful token navigation without inline narrative text. Native row heights remain unchanged.

## Updating
Replace files in the existing extension folder, reload the extension, and refresh GMGN and FOMO. No settings reset is needed.

## Security and privacy
No new permissions, polling or trading actions. Existing passive FOMO integration and opt-in bounded diagnostics remain unchanged. Local private diagnostics are excluded from this package.
