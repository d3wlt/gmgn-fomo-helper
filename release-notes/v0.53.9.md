# better gmgn v0.53.9

## Highlights
- Developer M/L/migration-rate and ATH strip supports BSC, Robinhood Chain and Solana token cards.
- Preserve Solana address case; read the native creator counts without inventing missing zeros.
- Route ATH requests by the card chain and cache by chain plus creator. No cross-chain BSC fallback.
- Live native metadata and developer-history endpoints verified on all three chains.

## Installation
Extract ZIP, enable Developer mode in chrome://extensions and Load unpacked.

## Usage
Enable developer performance and inspect supported token cards. M is migrated tokens, L is launches, percent is migration rate. ATH is the highest market cap reported for that creator on that chain, not necessarily the current token. Missing counts remain --; unavailable ATH is omitted.

## Updating
Replace files, reload the extension, and refresh GMGN and FOMO tabs.

## Security and privacy
Read-only native metadata and same-site developer-history requests. No new permissions, external provider, trade execution or weakening of CSP. Native QuickBuy behavior is unchanged.
