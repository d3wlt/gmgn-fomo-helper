# GMGN FOMO Helper v0.53.31

## Highlights
- FOMO Tracking activity and FOMO Trending follow their native GMGN chain pickers. Linked pickers share the selection; deliberately unlinked panels keep separate selections.
- Changing chains immediately refilters retained rows without another provider request or Trending reconnect. Server rank order and chain-plus-contract identity are preserved.
- Remove the obsolete "Show FOMO activity for current chain only" extension checkbox. Old saved values no longer affect the feed.
- Validate committed picker values rather than guessing from the current token route or raw native storage. An unavailable or malformed observed picker hides FOMO rows instead of broadening the selection; legacy layouts without any native picker retain their prior all-chain view.

## Installation
Download the release ZIP and SHA-256 checksum, verify the checksum, and extract to a permanent folder. Open chrome://extensions or edge://extensions, enable Developer mode, select Load unpacked and choose that folder.

## Usage
Choose chains using GMGN's Tracking and Trending chain pickers. Keep Link enabled to synchronize their selections, or unlink to filter each panel independently. Select the FOMO source in Trending for automatic live updates. Following remains passive and needs an existing signed-in FOMO tab receiving native activity.

## Updating
Replace the files in the existing unpacked extension folder, reload the extension, then refresh GMGN and FOMO once. Keep the existing browser profile and extension identity to retain settings. Unpacked extensions do not update automatically from GitHub releases.

## Security and privacy
No new permissions, provider requests or trading paths are introduced. Native chain selections are read locally from committed public UI properties. This change does not alter token-page context, position-surge alerts, authentication or connection policy. Arc QuickBuy remains unavailable. Browser regressions use synthetic data; no live trades are executed. See PRIVACY.md for the full policy.
