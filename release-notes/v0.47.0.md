# better gmgn v0.47.0

## Highlights

This private English-only build preserves the interface enhancements from upstream version 0.46.27 while using a manual ZIP-only installation and update process.

- All maintained UI, notifications, documentation, scripts, comments, and tests are English.
- Non-English FOMO and DeBot narratives are translated into English with the browser-local Translation API.
- Original narrative text remains visible above its translation.
- Content confirmed as English is not translated.
- Releases contain only a versioned ZIP and SHA-256 checksum.

## Installation

Download the ZIP and matching checksum from this repository's GitHub Release. Verify the checksum, extract the archive to a permanent folder, enable Developer mode at `chrome://extensions` or `edge://extensions`, select **Load unpacked**, and choose the extracted folder.

## Usage

Open the popup to configure watched developers, alerts, FOMO/Pump feed integration, marked holders, and other interface features. Some data panels require you to be signed in to their corresponding website in the same browser profile.

## Updating

Updates are manual. Download and verify the new ZIP, replace the extracted files, then select **Reload** on the extension card.

## Security and privacy

The extension contains no analytics, remote executable code, wallet signing, or transaction execution. Supported-site sessions and settings remain in browser-local extension storage and are used only for the documented site integrations. This project is independent and is not affiliated with the supported services or the original upstream author.
