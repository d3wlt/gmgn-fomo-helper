# GMGN FOMO Helper v0.53.26

## Highlights
- Correct FOMO Trending's source: observe the existing FOMO tab's native, server-ordered `trending_tokens` stream instead of the different REST ranking snapshot.
- Keep the selected FOMO view when switching browser tabs or when native markup remounts, without starting a request. Explicit native-tab selection, close, disable and account invalidation clear the selection.
- Mirror validated native filtering/frozen order and mounted-row display prices, with an explicit stream fallback and unknown values preserved.
- Match GMGN-native styling: compact 40px rows, inherited typography, gold market cap, secondary price and green/red 24-hour changes.

## Installation
Download and extract the release ZIP, then load its folder through `chrome://extensions` with Developer mode enabled. For an existing unpacked installation, replace the files in its existing folder and reload that extension to retain its identity and settings.

## Usage
In your existing signed-in FOMO tab, open **Tokens → Trending** so FOMO itself receives the stream. Then open native **Trending → FOMO** on GMGN. **Refresh** reads the latest already-observed snapshot from worker memory without a REST request. Returning to the GMGN browser tab restores the previously displayed FOMO view; Refresh is available to read newer observations.

## Updating
Reload the existing extension, then refresh the FOMO and GMGN pages to initialize the updated observers. No settings reset is required. Do not assume that publication alone updates unpacked extensions.

## Verification boundaries
Native-view mode mirrors validated committed hidden-token filtering and hover-frozen membership/order, plus mounted-row display prices. Offscreen chart overrides and silent offscreen-only commits are not guaranteed; unsupported views fall back explicitly to stream order. These are observed snapshots, not independently refreshed quotes. Worker/browser restart can require a fresh native snapshot. Stale snapshots expire within five minutes.

## Security and privacy
No helper-created sockets, subscriptions, ranking requests, extra account lookups or Following polling. Native traffic is observed through the existing bounded MAIN → isolated → worker bridge, with document/account/epoch checks. The user-triggered Trending read is memory-only. Existing token-panel API features remain separate. Native QuickBuy can execute a real trade only when explicitly activated; verification does not place trades.
