# better gmgn v0.51.0

## Highlights

- Replaces the optional 985monitor feed connector with J7Tracker.
- Injects account-filtered J7Tracker FOMO buys, sells, and narratives into GMGN and DeBot tracking feeds.
- Injects J7Tracker Pump.fun callouts and replies with explicit `J7 · Pump`, `Callout`, and `Reply` labels.
- Uses bounded `social_history` catch-up plus account-isolated live FOMO/Pump Socket.IO events, deduplication, timestamp ordering, local token blocking, and visible connection/expiry status.
- Removes 985monitor host access and its remote marked-holdings dependency.

## Installation

Verify the versioned ZIP against its SHA-256 checksum. Extract it to a permanent folder, enable Developer mode at `chrome://extensions`, then select **Load unpacked** and choose that folder.

## Usage

1. Sign in at `https://j7tracker.io/` in the same Chrome profile and open the page once so the extension can mirror the existing browser session.
2. Open the extension settings and confirm that **J7Tracker connected** is shown.
3. Keep **Insert FOMO activity into tracking** and/or **Insert Pump activity into tracking** enabled.
4. Refresh GMGN or DeBot. J7Tracker activity from accounts you track is inserted by event time alongside native rows.

J7Tracker FOMO contributes buys, sells, and narratives. J7Tracker Pump contributes callouts and replies; it is not represented as wallet-trade activity.

## Updating

Replace files in the existing unpacked-extension folder, select **Reload** in Chrome's extension manager, then refresh J7Tracker, GMGN, and DeBot tabs. Unpacked extensions do not update automatically.

## Security and privacy

The extension mirrors the J7Tracker session already held by the signed-in J7Tracker page into Chrome extension-local storage and uses it only with J7Tracker's tracked-list, social-history, and live social-event endpoints. The Socket.IO client and its full MIT notice are packaged locally; no executable code is downloaded at runtime. The extension adds no wallet signing, transaction execution, analytics, or secret-key collection.

Automated tests use synthetic account data. The public J7Tracker Socket.IO path and invalid-session response were checked live without credentials; account-specific history still requires a signed-in smoke test.
