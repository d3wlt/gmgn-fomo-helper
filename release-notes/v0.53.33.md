# GMGN FOMO Helper v0.53.33

## Highlights
- Add a real sorting dropdown to Community FOMO Thesis: Newest first, Oldest first and Most liked.
- Most liked uses newer posts first for ties and places unknown like counts last. Sorting only rearranges loaded posts, without extra history requests or reconnects.
- Keep the selected order across token switches and reopening within the page; page reload resets to Newest first. Incoming updates respect the selected order and preserve the reading anchor. Explicit sort changes return to the top.
- Keep the sort and Refresh controls together on the narrow 220px panel.

## Installation
Download the release ZIP and SHA-256 checksum, verify the checksum, and extract to a permanent folder. Open chrome://extensions or edge://extensions, enable Developer mode, select Load unpacked and choose that folder.

## Usage
Open GMGN Community → FOMO Thesis and choose an order from the dropdown beside the loaded count. Sorting covers only the available loaded posts, not the token's entire history. The feed retains up to 200 newest received posts; Oldest first does not fetch older history, and Most liked is not an all-time ranking.

## Updating
Replace the files in the existing unpacked extension folder, reload the extension, then refresh GMGN and FOMO once. Keep the existing browser profile and extension identity to retain settings. Unpacked extensions do not update automatically from GitHub releases.

## Security and privacy
No new permissions, network requests, persistent storage or trading actions. Sorting stays in page memory and preserves the existing token/account cleanup boundaries. See PRIVACY.md for the full policy.
