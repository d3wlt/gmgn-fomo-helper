# GMGN FOMO Helper v0.53.39

## Highlights
- Use five Trending market-cap ranges: **< $100K**, **$100K–$1M**, **$1M–$10M**, **$10M–$100M**, and **$100M+**.
- Keep Unknown separate for missing or invalid market caps.
- Preserve current-list percentages, leading-chain ties, expandable chain breakdowns, tracker-matching stripes and ten-second new-entry highlights.

## Usage
Open FOMO in GMGN's visible Trending panel. Statistics describe only the displayed coins. Each range includes its lower bound and excludes its upper bound: exactly $1M belongs to $1M–$10M, and exactly $100M belongs to $100M+. Main percentages include Unknown in the denominator; View details shows each chain's share within its range. Hover-held rows and statistics remain aligned.

## Installation
Download the ZIP and SHA-256 checksum, verify and extract to a permanent folder. Open chrome://extensions, enable Developer mode and Load unpacked. See GUIDE.md for complete instructions.

## Updating
Replace the existing unpacked files, reload the extension, then refresh GMGN and FOMO. Use the same browser profile and extension identity to preserve settings. Unpacked extensions do not automatically update from GitHub Releases.

## Security and privacy
No new permissions, provider requests, sockets or persistence. This changes only local market-cap bucketing and labels, with updated synthetic browser regressions. Native trading controls are unchanged; no live trades are performed for verification.
