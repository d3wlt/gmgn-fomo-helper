# better gmgn v0.53.0

## Highlights

This version targets the **direct FOMO Following lane**, not J7Tracker.

- Replace global-trading-activity-only collection with source-specific Fomobot-derived per-user swaps and social theses, plus bounded token-thesis and active-position recovery.
- Keep swap IDs, comment IDs, provider event IDs, position IDs and genuine transaction hashes separate. Multiple fills and theses on one position must remain separate events.
- Render direct Following responses independently of the heavy page scanner; retain eligible events rather than silently dropping them at placement caps.
- Keep recent collection independent of historical continuity gaps. Coverage warnings describe incomplete recovery rather than pretending complete history.
- Keep bounded, account-isolated session state across MV3 worker restarts.

## Installation

Extract the runtime ZIP to a permanent folder. Open `chrome://extensions`, enable Developer mode, choose Load unpacked and select that folder. Chrome 116 or newer is required.

## Usage

Sign in to FOMO in the same browser profile, then open the GMGN tracker with the FOMO feed enabled. The direct Following lane uses your FOMO following list, not the separate Telegram bot's manually enrolled roster. Existing event-type, chain and blocked-token filters remain applicable. J7Tracker is independent and is not required for direct FOMO collection.

Collection is bounded polling, not a claim of a FOMO WebSocket or guaranteed real-time delivery. Upstream response time, following-list size, rate limits and recovery depth can affect coverage and latency. Synthetic regression tests do not establish authenticated production latency or provider completeness.

## Updating

Replace the unpacked extension files, click Reload on its extension card, and refresh GMGN. Unpacked extensions do not auto-update. No running Fomobot or existing browser profile is modified by the package build.

## Security and privacy

Requests use the existing browser-local FOMO session. No bot credentials, Telegram delivery code, wallet signing, trading execution or live-account fixtures are included. Session cache is bounded and account-isolated; raw credentials are not copied into collector cache. Runtime-only ZIP excludes tests, screenshots and local data.
