# GMGN FOMO Helper v0.53.40

## Highlights
- Stop rebuilding the entire FOMO Trending panel on every update. Existing containers, token rows and metric nodes are retained so normal value updates no longer invalidate inspected elements.
- Identical displayed snapshots cause no DOM mutations. Rank changes move the same chain/address-keyed rows; new and removed tokens are reconciled individually.
- Replace pseudo-element chain stripes with explicit, pointer-inert row elements. Preserve custom colours, chain labels, 40px row geometry and the separate ten-second new-entry highlight.
- Retain the five approved market-cap ranges, expandable details, held-list behavior and current-list denominators.

## Usage
Open FOMO in GMGN's visible Trending panel. Live values update in place. Token order can still legitimately change with rankings, while hover/focus/scroll holds remain available. The renderer fix was reproduced and verified in production-source browser tests. Explicit stripes are tested with host pseudo-elements disabled; visibility in the originally reported browser still needs confirmation after updating.

## Installation
Download the ZIP and SHA-256 checksum, verify and extract to a permanent folder. Open chrome://extensions, enable Developer mode and Load unpacked. See GUIDE.md for complete instructions.

## Updating
Replace the existing unpacked files, reload the extension, then refresh GMGN and FOMO. Use the same browser profile and extension identity to preserve settings. GitHub releases do not automatically update unpacked extensions.

## Security and privacy
No new permissions, provider requests, sockets or persistence. This is a local renderer and styling fix. Native trading controls are unchanged; no live trades are performed for verification. Browser regression snapshots are synthetic, not live account evidence.
