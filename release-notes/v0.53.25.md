# GMGN FOMO Helper v0.53.25

## Highlights
- Small exact-token (`=`) and similar-name (`≈`) indicators on native and FOMO tracker rows, relative to the open token. Exact identity is chain plus contract address, with case-sensitive Solana addresses. Similarity is not asset equivalence or a safety judgment.
- An optional compact Compare view uses bounded, previously observed metadata without a permanent floating card or extra market lookups.
- A FOMO tab inside native GMGN Trending loads rankings only on opening or manual Refresh. It preserves provider ordering, chain-specific navigation, native tabs/rows and explicit unknown, empty, loading, error and stale states.
- Account-scoped 60-second caching, coalescing, bounded shared pacing and Retry-After cooldowns. Logout/account changes invalidate pending body reads. Privy-to-FOMO account identity is verified when necessary through the existing authenticated current-user reader within that same on-demand load.

## Installation
Download `gmgn-fomo-helper-v0.53.25.zip` and its `.sha256` file, verify the checksum, extract to a permanent folder and select **Load unpacked** in `chrome://extensions` with Developer mode enabled. Repository access is required.

## Usage
On a GMGN token page, inspect the small tracker indicators or select **Compare** in the token-information header. Similar-name detection needs previously observed metadata for the open token; missing data remains unknown. Comparison retains at most 500 identities for 30 minutes, marks observations stale after five minutes and shows at most 50 similar candidates.

Open native **Trending**, then select **FOMO**. Keep your existing FOMO session signed in. Refresh respects the 60-second cache and shared cooldowns; stale ranking rows expire after five minutes. Switching away, closing, hiding or remounting restores native content. Prices and market caps are snapshots, not live quotes.

## Updating
Replace files in the existing unpacked extension folder, reload the extension and refresh GMGN and the existing FOMO tab. Keep the same browser profile; no settings reset is needed. Publication does not automatically reload unpacked extensions.

## Verification boundaries

Responsive fixtures cover 320/390/570/1280px. Native mount structure and endpoint semantics were inspected read-only in loaded official source; the new Trending tab has not been smoke-tested in the signed-in live host. Unsupported or changed native markup remains untouched. No real trades were used for verification.

## Security and privacy
No new permissions, independent Following polling, sockets, blocking or retired-provider integrations. Trending uses the existing browser-local authenticated FOMO session; when identity namespaces differ it first verifies the application user through authenticated `GET /v2/users/current`. Both reads occur only inside the user-triggered load, not a background timer. Token comparison is local-only. Credentials, browser profiles, diagnostics, tests and screenshots are excluded from the extension ZIP. Native Buy remains capable of executing a real trade only when explicitly activated.
