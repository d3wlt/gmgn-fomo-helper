# GMGN FOMO Helper v0.53.29

## Highlights
- Replace the coin icon with the selected green frog-eyes artwork, with a transparent exterior and preserved white eyes. Includes toolbar and popup sizes plus the source master.
- Thank the original better gmgn creator and contributors in the README, with links to the upstream project.
- Update discovery documentation to record the verified v0.53.28 release and its testing boundaries. Trading, authentication and feed behavior are unchanged.

## Installation
Download and verify the release ZIP and SHA-256 checksum, extract it, then load the folder unpacked from chrome://extensions with Developer mode enabled.

## Usage
Select FOMO in GMGN's bottom-toolbar Trending panel for automatic live updates. Following remains passive and needs an existing signed-in FOMO tab. This release changes artwork and documentation, not feature behavior.

## Updating
Replace the files in your existing unpacked extension folder and reload the extension. Refresh GMGN and FOMO once afterward. Keep the existing browser profile and extension identity to retain settings. Unpacked extensions do not update automatically from GitHub releases.

## Security and privacy
No permissions, endpoints, account behavior or trading controls are changed. The extension identity is preserved. Existing valid-session requirements and live-stream limitations remain unchanged; see PRIVACY.md. Attribution is not an endorsement by the original project.
