# better gmgn v0.53.15

## Highlights
- Rename the private repository to **gmgn-fomo-helper** and update documentation and download links.
- Remove J7Tracker integration: its authentication bridge, collectors, sockets, background work, host permissions, settings and J7-provided FOMO/Pump activity.
- Completely remove DeBot integration, including its scripts, styles, permissions and runtime paths. The extension now targets GMGN and FOMO only.
- Keep the passive native FOMO Following feed, original GMGN tracker, single merged scrollbar, token panels and token-page followed-holder count.
- Preserve hybrid holdings, Robinhood position alerts and native QuickBuy safety guards.
- Remove integration-only packaging/dependencies and add retirement regressions so old saved J7 settings cannot reactivate the provider.

## Verification
- Full local npm run verify passed, including actual MV3 restart, legacy J7 state retirement and absent DeBot injection/traffic.
- Live GMGN/FOMO smoke test confirmed the renamed extension, native and FOMO rows, and token-page holder count.
- Fixed stale off-screen native overscan metadata; a continuous live down/up test passed all 40 sampled scroll positions without missing expected rows or replacing the merged surface. No trades were executed.

## Installation
Download `gmgn-fomo-helper-v0.53.15.zip` and its `.sha256` checksum from this private release. Verify the checksum, extract the ZIP to a permanent folder, enable Developer mode at chrome://extensions and select Load unpacked.

## Usage
Keep an existing FOMO tab signed in and receiving native Alerts activity for the passive Following tracker. Open the FOMO profile if its following roster has not initialized. No J7Tracker tab or account is needed. Token panels and the token-page holder count retain their own scoped requests; Following activity remains passive.

Open GMGN's native Holding panel to initialize selected wallets for surge monitoring. Native QuickBuy uses GMGN's account and Following amount settings; activating it can execute a real trade. The helper does not submit trades automatically.

## Updating
Replace the files in your existing unpacked extension folder, reload the extension, and refresh GMGN and the existing signed-in FOMO tab. The extension key is preserved, so the repository rename does not require a new browser profile or reset your extension identity. Chromium does not auto-update unpacked extensions.

## Security and privacy
The repository remains private. Release packages contain only allowlisted runtime files, not browser profiles, credentials, local diagnostics or test fixtures. J7Tracker and DeBot permissions and runtime access are removed; native FOMO observation and supported GMGN features remain. Trade controls retain account/token validation and fail closed when their supported context is unavailable.
