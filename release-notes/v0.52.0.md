# better gmgn v0.52.0

## Highlights
- J7 FOMO/Pump normalized live pushes render on a dedicated animation frame, independent of the expensive card scanner and network refreshes.
- History merges with same-session live arrivals. Bounded extension-only session cache restores on service-worker wake; account changes invalidate cache and pending UI reads.
- Adaptive disconnected recovery, Chrome 116 minimum, and a 25-second supported `social_history` request on the existing authenticated socket (limit 1). The provider's observed Engine.IO ping interval is 30000ms, so it alone is not below Chrome's idle deadline. No invented ping event is emitted.
- Local bounded numeric receive-to-render diagnostics; no telemetry uploads.

## Installation
Extract the runtime ZIP, open chrome://extensions, enable Developer mode and Load unpacked. Requires Chrome 116 or later.

## Usage
Open GMGN or DeBot and sign in on j7tracker.io to synchronize your optional J7Tracker session. Existing feed filters and settings still apply. DeBot retains its notification/poll compatibility.

## Updating
Replace the unpacked extension files, reload the extension, and refresh GMGN/DeBot tabs.

## Security and privacy
No credentials are bundled. Session cache is bounded, expires after one hour and is isolated by a SHA-256 account/session fingerprint in extension-only chrome.storage.session. Logout clears it. Latency metrics remain in local content-script memory and contain numeric timings only. Offline synthetic browser measurements are not production latency guarantees. The supported authenticated history keepalive is exercised with synthetic acknowledgements; production authenticated acknowledgement/lifetime is not claimed.
