# better gmgn v0.47.2

## Highlights

This patch fixes the developer-performance hover card remaining attached to the cursor after a watched GMGN token card or chart is clicked. It preserves the wallet-tracker layout correction from v0.47.1 and the English-only, manual ZIP release model introduced in v0.47.0.

- The tooltip is dismissed before click interactions reach GMGN.
- It remains suppressed while the pointer is still over the clicked watched card, preventing immediate reappearance during chart updates.
- Stale or replaced card nodes automatically dismiss the tooltip instead of leaving it attached to pointer movement.
- Regression coverage retains the v0.47.1 wallet-tracker transform checks and adds click, suppression, and stale-target checks.

## Installation

Download the ZIP and matching checksum from this repository's GitHub Release. Verify the checksum, extract the archive to a permanent folder, enable Developer mode at `chrome://extensions` or `edge://extensions`, select **Load unpacked**, and choose the extracted folder.

## Usage

Open GMGN normally. Hovering a watched developer card still shows the full developer-performance details. Clicking the card or its chart dismisses the details until the pointer leaves the card; hovering again afterward shows them normally. Wallet-tracker FOMO and Pump insertions continue to preserve GMGN's own row positioning.

## Updating

Replace the files in the existing unpacked-extension folder with this release, then select **Reload** on the extension card. Refresh the GMGN tab afterward so its virtual tracker list is recreated cleanly.

## Security and privacy

The extension contains no analytics, remote executable code, wallet signing, or transaction execution. Supported-site sessions and settings remain in browser-local extension storage and are used only for the documented site integrations. This project is independent and is not affiliated with the supported services or the original upstream author.
