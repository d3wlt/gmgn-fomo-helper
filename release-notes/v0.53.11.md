# better gmgn v0.53.11

## Highlights
- Flap tax helper retained behind its existing popup toggle, now OFF by default. Only explicit true enables requests.
- Disabling removes injected badges/rows and sizing markers and restores hidden native tax chips.

## Installation
Extract ZIP and Load unpacked at chrome://extensions in Developer mode.

## Usage
Flap tax badge is optional and off by default. Enable it explicitly in the extension popup if wanted.

## Updating
Reload the extension and refresh GMGN/FOMO. Existing explicitly saved ON settings are preserved; switch Flap tax badge off once on those installations.

## Security and privacy
No new Flap RPC requests are initiated while disabled. Already-running requests may finish. No permissions, trade controls or CSP changes.
